## Definition of Done

Run checks based on the files you changed:

1. Always run `npm run policy-check` before PRs.
2. For TypeScript/app changes: `npm run type-check` and `npm run lint`.
3. For behavior changes: run relevant tests.
4. For database changes: run migration and seed checks.

---

## Change Discipline

1. Keep edits as small as possible.
2. Do not make unrelated refactors.
3. Do not introduce new abstractions unless required by the task.
4. Never use hard deletes for records that need an audit trail.
