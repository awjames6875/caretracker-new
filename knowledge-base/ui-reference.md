# UI Reference

This file captures the layout ideas from the reference CareTrackr app so future UI work stays consistent.

## Login Screen

- Split layout with a bold brand panel on the left and a clean sign-in card on the right.
- Left panel includes:
  - Program name and short subtitle
  - Big headline
  - Three short feature cards
- Right card includes:
  - Staff sign-in title
  - Name field
  - Date field
  - Four-digit PIN flow
  - Full-width primary button

## Worker Dashboard

- Compact top bar with program name, date, worker name, and simple actions.
- Welcome banner with one short tip.
- Theme card near the top with a small edit action.
- Week summary card with the current week and focus.
- Two-column content area:
  - Left: room setup checklist
  - Right: today's activity cards
- Activity cards show:
  - time
  - title
  - billing code badge
  - tap-to-open details
- Child picker sits below the activity area with search and selected chips.
- Primary action at the bottom opens a modal to save what staff saw.

## Save Modal

- Show selected children at the top.
- Group checkboxes by simple skill area.
- Include one result field, one bright-spot checkbox, and one notes box.
- Show the activity name and billing code at the bottom.

## Visual Direction

- Use one strong blue accent.
- Use soft off-white and slate backgrounds.
- Keep cards bright, rounded, and lightly shadowed.
- Prefer large touch targets and wide spacing.
- Use a more polished look than the reference app, but keep the same information order.
